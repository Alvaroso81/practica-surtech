# SurTech S.L. · Práctica global UD2 (SOR · 2.º SMR)

Práctica interactiva de usuarios y grupos locales en Windows Server 2025: comprobación del laboratorio, una semana de tickets en un servidor simulado (consola + `lusrmgr.msc`) y una misión final en el SRV01 real.

Es un único archivo `index.html`: no necesita servidor ni conexión a Internet. El progreso se guarda en el navegador.

## Publicar con GitHub Pages

1. Sube `index.html` a un repositorio público.
2. Ve a **Settings → Pages → Build and deployment**: *Deploy from a branch*, rama `main`, carpeta `/ (root)`.
3. En 1-2 minutos estará en `https://<usuario>.github.io/<repositorio>/`.

## Usarlo sin Internet

Copia `index.html` al equipo del alumno (o a CLIENTE01) y ábrelo con doble clic.
